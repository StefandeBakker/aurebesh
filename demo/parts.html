Use only what you need

Aurebesh has no dependencies, and its parts can be used on their own.

The editor Documentation GitHub

The converter for Word documents, the handling of tracked changes, the mentions, the comments, the search and the texts of a language each have an entry of their own. An entry loads that part and what it needs, nothing else: no editor, no toolbar, no styles. That is what a server wants, or a page that only shows or converts text.

1. Load a part and see what it costs

Each button loads one entry of the package, the way import('aurebesh/…') does in your code. The table lists the files that were fetched for it, and what you get. Shared code is fetched once, so a part that follows another can be smaller than it is alone.

3. In your code


import { toDocx, fromDocx } from 'aurebesh/docx';              // Word, 25 KB gzip
import { suggestionsIn, finalHtml } from 'aurebesh/suggestions'; // tracked changes, 8 KB
import { mentionsIn } from 'aurebesh/mentions';                  // 2 KB
import { commentIdsIn } from 'aurebesh/comments';                // 5 KB
import LABELS_NL from 'aurebesh/locales/nl';                     // 3 KB

import { Aurebesh } from 'aurebesh';                             // the editor: all of it

  
Loading these entries does nothing to the page and needs no browser: they can be imported on a server. Only aurebesh/element registers <aurebesh-editor> when it is loaded, and package.json says so (sideEffects), so that a bundler can leave out the rest when it is not used.

  
The editor itself, aurebesh (the last button above), still has all of these parts in it. A version of the editor without them, to which you add what you need, is the next step.
