Aurebesh

A lightweight, dependency-free WYSIWYG editor for the web.

GitHub npm Documentation
  • No dependencies
  • Plain HTML, React, Vue, Angular
  • Paste from Word and Google Docs
  • Tables: merge cells, drag column widths
  • Right-to-left text
  • HTML, Markdown or text output
  • Built-in sanitizing

Try it

This is Aurebesh. Select some text and use the toolbar, or type # at the start of a line for a heading and - for a list. Paste something from Word or Google Docs to see it come in clean.

  • Rich text, lists and quotes
  • Tables you can merge and resize
  • Code blocks with colours
