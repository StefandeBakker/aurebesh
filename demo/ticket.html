Ticket layout

Build a receipt visually, with fields, sizes and conditions. The panel shows what it prints and the template code.

  1. Pick a part of the ticket with the tabs above the editor. Click a line and use [*] to insert a field, or […] for a command (euro sign, logo, cut, include).
  2. Select text and pick a size or alignment. Select text and press If to make it depend on a field.
  3. On the right: Preview is this part, Ticket is the whole ticket with the test data (products and payments repeat), Test data is where you change that data, Code is the template.
